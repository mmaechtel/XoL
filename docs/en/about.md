## About the Documentation

The author of this documentation has spent a long time researching and experimenting in various forums and other sources until his own simulation system was available in its current full expansion stage. The switch to the Linux operating system has more than paid off in terms of performance and stability. These experiences motivated him to compile the most important techniques and tools to provide others with a professional introduction to working with the simulator.

AI-assisted tools are used in the creation and maintenance of this documentation. All content is editorially reviewed and verified against primary sources.

### Target Audience

This documentation is aimed at experienced Linux users who want to run X-Plane on Linux with maximum performance. A working Linux installation, comfort with the command line, and basic system administration skills are assumed. Topics range from GPU driver configuration and kernel tuning to filesystem optimization, requiring a willingness to engage with low-level system concepts.
