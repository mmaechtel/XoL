# VATSim

VATSIM (Virtual Air Traffic Simulation Network) is the world's largest network for virtual flight simulation with realistic air traffic and air traffic control.

## Current Flight Routes

Based on VATSIM Bookings and Events, current flight routes are regularly calculated and made available:

📄 **[View Current VATSIM Flight Routes](https://atc.emvisio.de)**

### How does it work?

A script regularly searches for VATSIM Bookings and Events and calculates possible flights with maximum ATC coverage based on controller coverage and events. The web app then displays possible flights including statistical information, interactive maps and detailed controller schedules.

**Special feature:** The calculations are usually done with A320 speed (since this aircraft type is used most frequently). If you're flying faster, the time windows fit even better!

## What is VATSIM?

VATSIM offers pilots and air traffic controllers the opportunity to fly and work in a realistic environment. The network simulates real air traffic operations with:

- Realistic flight plans
- Live air traffic controllers
- Weather data
- Air traffic rules

## Getting Started

To begin with VATSIM, you need:

1. **VATSIM Account**: Register for free at [vatsim.net](https://vatsim.net)
2. **VATSIM Client**: Download a compatible client (e.g., vPilot, xPilot)
3. **Flight Plan**: Create a realistic flight plan
4. **Training**: Visit the VATSIM Academy for basics
