# Cleveland Hopkins International Airport (KCLE) - JSD Scenery

Cleveland Hopkins International Airport (KCLE) is a significant commercial airport in the northeastern United States, developed by JSD Scenery in Version 2.0 for X-Plane 12. This scenery provides a detailed representation of the airport and its surroundings.

## About the Airport

Cleveland Hopkins International serves as the primary airport for the city of Cleveland, Ohio, and functions as a hub for several airlines. The airport features three runways and a modern terminal building.

**Interesting Facts:**

- The longest runway (06R/24L) measures 3,048 meters and can accommodate all aircraft types
- The airport was the first in the USA to feature a fully automated baggage handling system
- The terminal building was completely modernized in 2016 and features a unique glass facade

## Scenery Features

The JSD Scenery Version 2.0 offers the following main features:

- Fully modeled buildings and structures
- Detailed runway and taxiway markings
- Dynamic lighting
- Optimized performance
- HD textures
- X-Plane 12 adaptations

The scenery supports the following systems and technologies:

### System Requirements

The scenery has the following system requirements:
