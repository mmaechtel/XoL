# Tools

Seven utilities for plugin development and day-to-day operations. [DataRefTool](datareftool.md) browses, searches, and edits X-Plane's datarefs in real time — the first stop when debugging a plugin or script. [Little XpConnect](littlexpconnect.md) feeds position, weather, and AI traffic to Little Navmap. [SkunkCrafts Updater](skunkcrafts_updater.md) keeps addons current with differential downloads and comes with glibc notes for Debian. [XGS](xgs.md) rates every landing by sink rate, G-forces, and centerline deviation. [XLinSpeak](xlinspeak.md) is Linux-only by design: it supplies the text-to-speech that X-Plane gets from the operating system on Windows and macOS, via speech-dispatcher — the page also covers Piper TTS Manager, a separate FlyWithLua script for neural voices. The [WINCTRL plugin](winctrl.md) drives WINCTRL cockpit panels over USB HID without SimAppPro.

[XOrganizer](xorganizer.md) is the exception in this list: a Windows-only .NET application that runs under Wine at best unreliably — the page documents the limits and points to a native alternative for sorting `scenery_packs.ini` (see [Components](../../scenery/aufbau_quellen/scenery_components.md) for why that order matters).

- **[DataRefTool](datareftool.md)** — DataRef browser and search
- **[Little XpConnect](littlexpconnect.md)** — Connection to Little Navmap
- **[SkunkCrafts Updater](skunkcrafts_updater.md)** — Automatic addon updates
- **[XGS](xgs.md)** — Landing rate display
- **[XLinSpeak](xlinspeak.md)** — Speech output for X-Plane on Linux
- **[X-Plane WINCTRL Plugin](winctrl.md)** — WINCTRL cockpit panels (displays, LEDs, encoders)
- **[XOrganizer](xorganizer.md)** — Scenery manager and scenery_packs.ini editor
