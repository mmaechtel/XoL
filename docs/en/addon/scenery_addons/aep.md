# Airport Enhancement Package (AEP)

The [Airport Enhancement Package (AEP)](../../glossary.md#airport-enhancement-package-aep) by X-Codr Designs is a scenery addon for [X-Plane](../../glossary.md#x-plane) that enhances default airports with more detailed models and high-resolution textures.

## Background

- **Developer:** X-Codr Designs
- **Website:** [x-codrdesigns.com/xp-aep](https://www.x-codrdesigns.com/xp-aep)
- **Platforms:** Windows, macOS, Linux
- **Compatibility:** X-Plane 12

## Features

AEP replaces default [airport elements](../../glossary.md#airport-elements) with new developments:

- **Buildings and facades:** Airport buildings, facades, static vehicles, and ground objects
- **Runway equipment:** Lights, beacons, and navigation aids
- **[Ground markings](../../glossary.md#ground-markings):** Revamped ground textures with procedurally generated skids, oil leaks, and regional grunge, plus ultra-detailed decals and marking textures based on FAA guidelines
- **Vegetation:** Default [airport vegetation](../../glossary.md#airport-vegetation) replaced with new 3D vegetation
- **Custom taxi signs:** The bundled AEP Live plugin replaces taxiway signs in real time with FAA-conformant models, including at third-party airports

All models are equipped with modern technology:

- Decal-based detail textures with normal maps, delivering close-up detail at lower VRAM cost
- [PBR](../../glossary.md#pbr) normalmaps for details and reflections
- LODs for good performance at high detail level
- Simple interiors for additional depth
- Regionalization

## Value in Flight Simulation

AEP upgrades default airports worldwide in a single package — an alternative to buying payware scenery for each individual airport. The PBR materials and detail decals create a significantly more realistic appearance than the default elements. Through regionalization, buildings and objects adapt to the respective region.

## Installation

AEP is payware and is purchased from the X-Plane.org store, which the [official website](https://www.x-codrdesigns.com/xp-aep) links to. Extract both included folders (`AEP` and `AEP Overlays`) to `Custom Scenery/`; the `scenery_packs.ini` is updated automatically on the next X-Plane startup. Subsequent updates are delivered through the SkunkCrafts Updater.

**System requirements:**

- Graphics card with 8 GB or more [VRAM](../../glossary.md#vram-video-ram) recommended
- Approximately 2 GB download size
