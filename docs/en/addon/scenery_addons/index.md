# Scenery Plugins

Eight plugins and libraries that visually extend X-Plane's default world. [XRoads](xroad.md) is a scenery library rather than a plugin: it hides X-Plane's road polygons on Ortho4XP tiles so the real roads in the satellite imagery show through, while bridges, highways, and railways stay visible — with Linux compilation instructions. [Airport Enhancement Package](aep.md) upgrades default airports with better buildings, ground markings, vegetation, and PBR textures. [xa-snow](xa-snow.md) and [NOAA Weather](noaa_weather.md) both draw on real-world NOAA data — location-specific snow depth on the one hand, snow coverage plus METAR comparison on the other. [LST](lst.md) animates airports with vehicles, pedestrians, and ground equipment on defined routes, and [Bay's Lighting Mod](bays_lighting_mod.md) reworks airport, night, and cockpit lighting plus cloud scattering. [XP BirdState](xp_birdstate.md) adds bird flocks matched to region, season, and weather — a commercial plugin with an official Linux build — and [Night Sky Fix](night_sky_fix.md) replaces the star catalog with a denser one (Milky Way at 900,000 stars) and optionally corrects star brightness with a FlyWithLua script.

All eight run on Linux; two have dependencies worth knowing before installing: Bay's Lighting Mod needs FlyWithLua, NOAA Weather needs XPPython3 (see [Scripting](../scripting/index.md)).

- **[Airport Enhancement Package](aep.md)** — Enhance airport surroundings
- **[xa-snow](xa-snow.md)** — Improved snow rendering

- **[LST](lst.md)** — Living Scenery Technology
