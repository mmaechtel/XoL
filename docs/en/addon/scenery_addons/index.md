# Scenery Plugins

Six plugins and libraries that visually extend X-Plane's default world. [XRoads](xroad.md) is a scenery library rather than a plugin: it hides X-Plane's road polygons on Ortho4XP tiles so the real roads in the satellite imagery show through, while bridges, highways, and railways stay visible — with Linux compilation instructions. [Airport Enhancement Package](aep.md) upgrades default airports with better buildings, ground markings, vegetation, and PBR textures. [xa-snow](xa-snow.md) and [NOAA Weather](noaa_weather.md) both draw on real-world NOAA data — location-specific snow depth on the one hand, snow coverage plus METAR comparison on the other. [LST](lst.md) animates airports with vehicles, pedestrians, and ground equipment on defined routes, and [Bay's Lighting Mod](bays_lighting_mod.md) reworks airport, night, and cockpit lighting plus cloud scattering.

All six run on Linux; two have dependencies worth knowing before installing: Bay's Lighting Mod needs FlyWithLua, NOAA Weather needs XPPython3 (see [Scripting](../scripting/index.md)).

- **[xa-snow](xa-snow.md)** — Improved snow rendering

- **[LST](lst.md)** — Living Scenery Technology
