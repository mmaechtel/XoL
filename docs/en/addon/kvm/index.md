# Via KVM

Three Windows-only addons made usable on Linux through [KVM virtualization](../../linux/extensions/kvm.md): My FS Flights for logbook and statistics, MobiFlight for hardware cockpit integration, and SayIntentions.AI for AI-powered ATC communication.

- **[My FS Flights](myfs_flights.md)** — Logbook and statistics
- **[MobiFlight](mobiflight.md)** — Hardware cockpit integration
- **[SayIntentions.AI](sayintentions.md)** — AI-powered ATC communication
