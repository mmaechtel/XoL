# ToLiss Mods

Aircraft modifications for the ToLiss fleet (A319, A320 CEO/NEO, A321 CEO/NEO) — 3D model replacements and conversions that go beyond scripting. All of them ship native Linux installers or platform-independent OBJ files; the mods that edit the aircraft's own files have to be reinstalled after every ToLiss update.

- **[Easy Freighter](easy_freighter.md)** — A321 P2F cargo door conversion
- **[Carda Realistic Engine Mods](carda_engines.md)** — High-detail 3D engine replacements
- **[Durantula Wing Enhancement MOD](durantula_wing_mod.md)** — New flaps and native wingflex
- **[RealWings](realwings.md)** — Complete wing replacement
- **[ToLiss Photon](toliss_photon.md)** — Exterior and cockpit lighting overhaul
