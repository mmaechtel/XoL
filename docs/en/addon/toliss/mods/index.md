# ToLiss Mods

Aircraft modifications for the ToLiss fleet (A319, A320 CEO/NEO, A321 CEO/NEO) — 3D model replacements and conversions that go beyond scripting. All of them ship native Linux installers or platform-independent OBJ files; the mods that edit the aircraft's own files have to be reinstalled after every ToLiss update. Scripts and plugins for the same aircraft live one level up in the [ToLiss Ecosystem](../index.md), sound packs under [Sounds](../../sounds/index.md).

The mods differ in how deep they cut: [Easy Freighter](easy_freighter.md) is a drop-in object plus a livery setting, [Carda Realistic Engine Mods](carda_engines.md) patch the `.acf` to reference new engine models, [Durantula Wing Enhancement MOD](durantula_wing_mod.md) and [RealWings](realwings.md) rework or replace the wing, and [ToLiss Photon](toliss_photon.md) re-authors the exterior lights in the OBJ files, with a native plugin for beacon and strobe flashing and an optional cockpit lighting set. Each page names the developer and the download source and explains the installation, so the Linux path is clear before anything is copied into the aircraft folder.

- **[Easy Freighter](easy_freighter.md)** — A321 P2F cargo door conversion
- **[Carda Realistic Engine Mods](carda_engines.md)** — High-detail 3D engine replacements
- **[Durantula Wing Enhancement MOD](durantula_wing_mod.md)** — New flaps and native wingflex
- **[RealWings](realwings.md)** — Complete wing replacement
- **[ToLiss Photon](toliss_photon.md)** — Exterior and cockpit lighting overhaul
