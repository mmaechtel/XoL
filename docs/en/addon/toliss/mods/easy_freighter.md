# Easy Freighter

Easy Freighter simulates an A321 freighter conversion (A321P2F/A321PCF) for the ToLiss A321: the large main-deck cargo door of a converted freighter appears on the fuselage, turning the passenger jet into a cargo aircraft visually. The kit is a drag-and-drop object for the aircraft's `objects/` folder — no installer, no platform-specific files, so it works on Linux exactly as on Windows or macOS. Whether the door shows is decided per livery: the cargo livery must contain `external_Extras = YES` and `custom_Cabin = F` in its `livery.tlscfg`; liveries without these lines keep the standard passenger fuselage. A demonstration livery is included as a template. A separate version also exists for the A320. Not officially approved by ToLiss.

**Setup**

1. Copy the kit object into the `objects/` folder of the ToLiss A321
2. Add `external_Extras = YES` and `custom_Cabin = F` to the `livery.tlscfg` of the cargo livery
3. Load that livery in X-Plane — the cargo door appears on the exterior model
