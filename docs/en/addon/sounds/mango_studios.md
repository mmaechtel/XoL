# Mango Studios Sound Packs

Mango Studios produces FMOD-based sound replacements for the complete ToLiss fleet in [X-Plane](../../glossary.md#x-plane) 12. Each pack replaces the default sound banks with real-aircraft recordings covering engines, cockpit switches, warning systems, environmental effects, and cabin sounds. An included plugin adds passenger reactions and PA announcements.

## Background

- **Developer:** Mango Studios (Simon)
- **Website:** [mangostudiossounds.com](https://www.mangostudiossounds.com/)
- **Support:** [Discord](https://discord.gg/YUG4yTz)
- **Compatibility:** X-Plane 11 and X-Plane 12
- **Platforms:** Windows, macOS, Linux

The **ToLiss Airbus Family Bundle** combines the A319, A320, and A321 packs at a reduced price.

## Features

- **Engine sounds:** Full lifecycle per variant (startup, spool, reverser, exhaust, flyby)
- **Cockpit:** Real-aircraft switch, button, and knob recordings for overhead, pedestal, and FCU
- **Warnings:** Complete EGPWS callout set, TCAS, master warning/caution, stall warning, AP disconnect
- **Environmental:** Gear sounds, ground roll, flap/spoiler drag, rain (interior/exterior), cockpit rattle
- **Cabin:** Air conditioning ambience, PA announcements (captain + flight attendant), passenger reactions (toggleable via included plugin)

## Installation

1. Back up the original `fmod/` folder in the aircraft directory
2. Extract the archive
3. Copy the `fmod/` and `plugins/` folders into the ToLiss aircraft directory (e.g., `Aircraft/ToLissA321/`)
4. Replace existing files when prompted

The included Mango Studios Sounds Plugin provides an in-game menu for volume adjustments and passenger reaction toggles.
