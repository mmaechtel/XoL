# Sounds

Sound packs replace X-Plane's default FMOD sound banks — engines, cockpit switches, warning systems, and cabin audio. Both packs documented here target the ToLiss Airbus fleet, install into the aircraft folder, and each brings a small plugin of its own; both run on Linux.

[KOSP Project](kosp_project.md) is a single package for the A319, A320, and A321 (CEO and NEO) covering four engine variants — CFM56, IAE V2500, LEAP-1A, PW1000G — with cockpit sounds recorded on a real A320; A330 and A340 are not supported. [Mango Studios](mango_studios.md) sells separate packs per aircraft, including the A330-900 and A340-600, and adds passenger reactions and PA announcements through an included plugin. Which one fits depends on the fleet flown: for the A32x family both are options, for the wide-bodies only Mango Studios.

- **[KOSP Project](kosp_project.md)** — Full soundscape for X-Plane
- **[Mango Studios](mango_studios.md)** — Sound packs for various aircraft
