# FlyWithLua Scripts

Nine FlyWithLua scripts for daily use: from 3D Rain Stop, Dynamic Rain Rate and AutoHaze for realistic weather and visibility, through X-ProTurb for physics-based turbulence, SimBrief integration and SimLoad Manager for scenery management, to SimReaperXP for memory cleanup and SGES for ground effect simulation.

- **[3D Rain Stop](3drainspeedstop.md)** — Stop rain in cockpit with closed windows
- **[Dynamic Rain Rate](rain_rate.md)** — Dynamic rain intensity
- **[SimBrief Simple OFP](simbrief_simple_ofp.md)** — SimBrief flight plan in the simulator
- **[SimLoad Manager](simloadmanager.md)** — Scenery load manager
- **[SimReaperXP](simreaperxp.md)** — Memory cleanup during runtime
- **[SimScreen Overlay](simscreenoverlay.md)** — Screen overlay for flight data
- **[SGES](sges.md)** — Ground Effect Simulation
- **[X-ProTurb](xproturb.md)** — Physics-based turbulence engine
- **[AutoHaze](autohaze.md)** — Haze correction from real atmospheric data

A further FlyWithLua-driven addon is documented with the scenery plugins, because its substance is a texture package rather than a script: **[Bay's Lighting Mod](../scenery_addons/bays_lighting_mod.md)**.
