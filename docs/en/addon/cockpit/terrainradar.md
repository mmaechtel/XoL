# TerrainRadar

TerrainRadar is a native [plugin](../../glossary.md#plugin) that provides an EGPWS terrain display (Enhanced Ground Proximity Warning System) and a Vertical Situation Display (VSD) in X-Plane. The terrain depiction is color-coded relative to the current altitude: black (>1,000 ft below), yellow (<1,000 ft), red (<100 ft — collision danger).

## Background

- **Developer:** Denis Antontsev (DrGluck) and Sergey Popovichev (Vanger)
- **Download:** [X-Plane.org](https://forums.x-plane.org/files/file/37864-terrain-radar-vertical-situation-display/)
- **Platforms:** Windows, macOS, Linux (native binaries)
- **Compatibility:** X-Plane 12

The plugin operates in two modes: for supported aircraft, it integrates directly into the navigation display (TERR button); for all other aircraft, a freely positionable overlay window is available.

## Features

- **Terrain display:** Color-coded terrain depiction on the ND or as an overlay window
- **Vertical Situation Display (VSD):** Terrain profile in vertical cross-section along the flight path
- **Peaks mode:** Continues showing terrain peaks even at cruise altitude
- **EGPWS alerts:** Terrain collision prediction and warnings
- **Overlay window:** Detachable, scalable, movable to a second monitor
- **Wide aircraft support:** Integrated ND mode for Zibo 737, FlightFactor 777, ToLiss-compatible aircraft, iniSimulations A300/A310, and many more

## Value in Flight Simulation

Terrain awareness is safety-critical during approaches in mountainous terrain and low-visibility conditions. TerrainRadar provides the visual terrain display that is standard equipment in real transport aircraft. Thanks to the universal overlay mode, it also works with aircraft that do not include a built-in terrain display.

!!! note "X-Plane 12.3+"

    X-Plane 12.3 introduced native terrain display on the X1000 avionics instruments. TerrainRadar continues to add value through broader aircraft support, the VSD feature, and the universal overlay mode.

## Installation

**Download:** [X-Plane.org](https://forums.x-plane.org/files/file/37864-terrain-radar-vertical-situation-display/)

Extract the `TerrainRadar` folder to `Resources/plugins/`.
