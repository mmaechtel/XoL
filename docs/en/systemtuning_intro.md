Two topics that belong together: **System Tuning** optimizes kernel, scheduler, and power management for low latency — **System Monitoring** provides the tools to measure and verify the effect of these settings.

- [System Tuning](systemtuning.md) — Kernel parameters, CPU governor, interrupt affinity, NVMe tuning
- [System Monitoring](systemtools.md) — btop, turbostat, perf, mpstat and other analysis tools
