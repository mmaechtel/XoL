# Grundlagen

X-Plane verteilt seine Last auf drei Achsen — CPU, Speicher-I/O und Netzwerk —, die um gemeinsame Hardware-Ressourcen konkurrieren. Wo der Engpass liegt, wechselt je nach Flugphase und Konfiguration. Die Grundlagen-Sektion erklärt diese Zusammenhänge, bevor die folgenden Kapitel konkrete Optimierungen behandeln.
