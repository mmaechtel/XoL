# XOrganizer

XOrganizer ist ein leistungsstarkes Tool zur Verwaltung und Organisation von X-Plane-Addons. Es hilft bei der Verwaltung von Sceneries, Plugins und anderen Addons, um Konflikte zu vermeiden und die Performance zu optimieren.

## Installation

1. Besuchen Sie die [offizielle Website](https://www.4xplane.nl/xorganizer/) von XOrganizer
2. Auf der offiziellen Website finden Sie Informationen zum Kauf des Tools
3. Nach dem Kauf erhalten Sie den Download-Link und können das Tool in einem Ordner Ihrer Wahl installieren

## Grundlegende Verwendung

1. **Scenery-Verwaltung**:
   - Automatische Erkennung und Kategorisierung von Sceneries
   - Drag & Drop-Funktion zur Neuanordnung
   - Konfliktprüfung zwischen Sceneries

2. **Plugin-Management**:
   - Übersicht über alle installierten Plugins
   - Einfache Aktivierung/Deaktivierung von Plugins
   - Plugin-Konfigurationsverwaltung

3. **Profilverwaltung**:
   - Erstellung verschiedener Profile für unterschiedliche Fluggebiete
   - Schnelles Wechseln zwischen Profilen
   - Automatische Anpassung der Scenery-Reihenfolge

## Erweiterte Funktionen

- **Performance-Optimierung**: Automatische Vorschläge zur Verbesserung der Performance
- **Backup-Funktion**: Sichern und Wiederherstellen von Konfigurationen
- **Scenery-Bibliothek**: Verwaltung von Scenery-Downloads und Installationen
- **Log-Analyse**: Automatische Analyse von X-Plane-Logs auf Probleme

## Tipps und Tricks

- Erstellen Sie separate Profile für verschiedene Fluggebiete
- Nutzen Sie die Konfliktprüfung vor jedem Flug
- Führen Sie regelmäßige Backups Ihrer Konfiguration durch
- Aktualisieren Sie XOrganizer regelmäßig für neue Funktionen

## Fehlerbehebung

Bei Problemen:
1. Überprüfen Sie die Log-Dateien in XOrganizer
2. Stellen Sie sicher, dass Sie die neueste Version verwenden
3. Versuchen Sie, das Profil zurückzusetzen
4. Konsultieren Sie das [XOrganizer-Forum](https://forums.x-plane.org/index.php?/forums/forum/406-xorganizer/) für weitere Hilfe
