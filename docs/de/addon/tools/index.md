# Werkzeuge

Sieben Werkzeuge für Plugin-Entwicklung und den täglichen Betrieb. [DataRefTool](datareftool.md) durchsucht, beobachtet und bearbeitet X-Planes DataRefs in Echtzeit — die erste Anlaufstelle beim Debuggen eines Plugins oder Skripts. [Little XpConnect](littlexpconnect.md) liefert Position, Wetter und KI-Verkehr an Little Navmap. [SkunkCrafts Updater](skunkcrafts_updater.md) hält Addons per differenziellem Download aktuell und bringt glibc-Hinweise für Debian mit. [XGS](xgs.md) bewertet jede Landung nach Sinkrate, G-Kräften und Abweichung von der Mittellinie. [XLinSpeak](xlinspeak.md) ist bewusst Linux-only: Es liefert die Sprachausgabe, die X-Plane unter Windows und macOS vom Betriebssystem bekommt, über speech-dispatcher — die Seite behandelt zusätzlich Piper TTS Manager, ein separates FlyWithLua-Skript für neuronale Stimmen. Das [WINCTRL-Plugin](winctrl.md) steuert WINCTRL-Cockpit-Panels per USB HID ohne SimAppPro.

[XOrganizer](xorganizer.md) ist die Ausnahme in dieser Liste: eine Windows-only .NET-Anwendung, die unter Wine bestenfalls unzuverlässig läuft — die Seite dokumentiert die Grenzen und verweist auf eine native Alternative zum Sortieren der `scenery_packs.ini` (warum diese Reihenfolge zählt, steht unter [Komponenten](../../scenery/aufbau_quellen/scenery_components.md)).

- **[DataRefTool](datareftool.md)** — DataRef-Browser und -Suche
- **[Little XpConnect](littlexpconnect.md)** — Verbindung zu Little Navmap
- **[SkunkCrafts Updater](skunkcrafts_updater.md)** — Automatische Addon-Updates
- **[XGS](xgs.md)** — Landungsbewertung
- **[XLinSpeak](xlinspeak.md)** — Sprachausgabe für X-Plane unter Linux
- **[X-Plane WINCTRL Plugin](winctrl.md)** — WINCTRL-Cockpit-Panels (Displays, LEDs, Encoder)
- **[XOrganizer](xorganizer.md)** — Szenerie-Verwaltung und scenery_packs.ini-Editor
