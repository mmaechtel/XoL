# Cockpit & Kamera

Neun Plugins für Cockpit-Funktionalität: AviTab als Electronic Flight Bag, XCamera für erweiterte Kamerasteuerung, Xchecklist für interaktive Checklisten mit Sprachausgabe, XTextureExtractor für Cockpit-Instrumente auf externen Displays, LinuxTrack und OpenTrack für Head-Tracking unter Linux, TerrainRadar für Geländedarstellung, KabinXP für die Passagierkabine und XP Walkaround für Pre-Flight-Inspektionen.

- **[AviTab](avitab.md)** — Electronic Flight Bag im Cockpit
- **[XCamera](xcamera.md)** — Erweiterte Kamerasteuerung
- **[Xchecklist](xchecklist.md)** — Interaktive Checklisten mit Sprachausgabe
- **[XTextureExtractor](xtextureextractor.md)** — Cockpit-Texturen auf externe Displays
- **[LinuxTrack](linuxtrack.md)** — Head-Tracking mit TrackIR unter Linux
- **[OpenTrack](opentrack.md)** — Head-Tracking mit Webcam oder IR unter Linux
- **[TerrainRadar](terrainradar.md)** — Gelände-Radar-Plugin
- **[KabinXP](kabinxp.md)** — Passagierkabinen-Ansicht
- **[XP Walkaround](xpwalkaround.md)** — Pre-Flight-Inspektion
