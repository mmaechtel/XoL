# XP Walkaround

XP Walkaround ist ein kommerzielles [Plugin](../../glossary.md#plugin) für [X-Plane](../../glossary.md#x-plane), das Pre-Flight-Inspektionen von außen ermöglicht — um das Flugzeug herumgehen, Außenelemente prüfen und mit Bremsklötzen, Türen und Remove-before-flight-Tags interagieren. Das Plugin läuft nativ unter Linux.

## Hintergrund

- **Entwickler:** VFRScenery
- **Store:** [X-Plane.org Store](https://store.x-plane.org/WalkAround-Plugin-for-X-Plane-12-and-11_p_1687.html) (kommerziell, $19.99)
- **Plattformen:** Windows, macOS, Linux
- **Kompatibilität:** X-Plane 11, 12

## Funktionsumfang

- **Außenrundgang:** In zwei Geschwindigkeiten um das Flugzeug herumgehen
- **Interaktive Elemente:** Bremsklötze, Remove-before-flight-Tags und Türen bei kompatiblen Flugzeugen (abhängig von der Unterstützung des Flugzeugentwicklers)
- **Steuerung:** E-Taste zum Aufstehen aus jeder Position, Leertaste + Klick für Außeninteraktion
- **Synchronisierte Schrittgeräusche:** Audioeffekte beim Gehen
- **Breite Flugzeugunterstützung:** Default-Aircraft, ToLiss, FlightFactor, IXEG, Rotate MD-11, Aerobask, CRJ, FlyJSim, Vskylabs

## Mehrwert in der Flugsimulation

XP Walkaround fügt eine Pre-Flight-Routine hinzu, die reale Pilotenabläufe nachbildet. Statt direkt ins Cockpit zu springen, lässt sich das Flugzeug von außen inspizieren — Steuerflächen, Triebwerkseinläufe und Fahrwerk visuell prüfen. Das erhöht die Immersion und fördert realistische Abfertigungsabläufe.

## Installation

**Download:** [X-Plane.org Store](https://store.x-plane.org/WalkAround-Plugin-for-X-Plane-12-and-11_p_1687.html)

Als Standalone-Plugin nach `Resources/plugins/` installieren. Unter Linux sind keine zusätzlichen Systempakete oder Konfigurationen erforderlich.

## Kostenlose Alternative: SimpleWalkaround

[SimpleWalkaround](https://forums.x-plane.org/files/file/96508-simplewalkaround/) ist ein kostenloses Plugin mit ähnlicher Walkaround-Funktionalität. Es nutzt WASD-Bewegungssteuerung, Sprint (C) und Ducken (X). Die frühere SASL3-Abhängigkeit wurde inzwischen entfernt.

!!! note "SimpleWalkaround Linux-Support nicht bestätigt"

    SimpleWalkaround wurde unter Windows getestet. Linux-Kompatibilität ist vom Entwickler nicht explizit bestätigt — es kann funktionieren, ist aber nicht garantiert.
