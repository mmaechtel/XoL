# Trusted Sources

Vertrauenswürdige Quellen für die Research-Skills. Nur URLs von diesen Domains dürfen mit WebFetch gelesen werden.

**Priorität beim Recherchieren:** Offizielle Doku und Standards > Akademisch/Wissenschaftlich > Community-Wikis > Fachmedien. Kommerzielle Quellen (Firmen-Blogs, Marketing) sind NICHT in dieser Liste und dürfen NICHT mit WebFetch gelesen werden.

**Quellenaktualität:** Nur Quellen ab 2024 aufwärts verwenden. Ältere Quellen nur, wenn keine aktuellere Alternative existiert und die Information nachweislich stabil ist (z.B. Kernel-Docs, POSIX-Standards, Architektur-Grundlagen).

## 1. Offizielle Projekt-Dokumentation

- docs.kernel.org — Linux Kernel Dokumentation (Sphinx)
- www.kernel.org — Linux Kernel Releases
- man7.org — Linux Man Pages, Michael Kerrisk
- www.x-plane.com — X-Plane Dokumentation, Downloads
- developer.x-plane.com — X-Plane Developer Portal, SDK
- docs.mesa3d.org — Mesa 3D Graphics Library
- pipewire.org — PipeWire Multimedia Framework
- liquorix.net — Liquorix Kernel (Desktop-optimiert)
- xearthlayer.app — xEarthLayer Addon-Dokumentation

## 2. Standards und Spezifikationen

- vulkan.org — Vulkan API Dokumentation
- registry.khronos.org — Khronos Group (Vulkan, OpenGL Spezifikationen)
- freedesktop.org — freedesktop.org Standards (XDG, D-Bus, Wayland-Protokoll)
- www.freedesktop.org — freedesktop.org (alternative Domain)
- gitlab.freedesktop.org — freedesktop.org Git-Repositories (Mesa, Wayland, PipeWire)

## 3. Akademisch und wissenschaftlich

- lwn.net — Linux Weekly News (Kernel-Entwicklung, bevorzugte Quelle für Linux-Themen)
- en.wikipedia.org — Allgemeine Referenz, Übersichtsartikel
- de.wikipedia.org — Deutsche Referenz

## 4. Community-Wikis und Dokumentation

- wiki.archlinux.org — Arch Linux Wiki (exzellente technische Doku)
- wiki.debian.org — Debian Wiki
- packages.debian.org — Debian Paket-Referenz
- manpages.debian.org — Debian Man Pages

## 5. Hersteller-Dokumentation

- us.download.nvidia.com — NVIDIA Downloads (US Mirror)
- www.nvidia.com — NVIDIA Offizielle Seite

## 6. Repositories und Code

- github.com — Open Source Repositories, READMEs
- raw.githubusercontent.com — GitHub Raw Content
- sourceforge.net — Open Source Projekt-Hosting

## 7. Fachmedien und Community (niedrigste Priorität)
